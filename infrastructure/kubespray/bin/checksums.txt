# sha256 of every artifact `make tools` downloads, one `<sha256>  <filename>` line
# each, in the format shasum -a 256 writes. This file is the pin: `make tools`
# refuses an artifact that is absent from it or does not match.
#
# It starts empty because no V31 checkout has fetched these versions yet. Fill it
# once per version, on a machine you trust, with:
#
#   make tools-pin        # downloads, checks against the checksum published
#                         # beside each artifact, appends the line here
#   git add bin/checksums.txt
#
# After that every `make tools` on every machine verifies against these lines and
# never consults upstream again. Bumping a version in versions.env invalidates
# nothing here - the filenames carry the version, so the old lines simply stop
# matching anything and the new ones need pinning.
